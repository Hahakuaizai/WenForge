# 小说工坊 NovelForge（v3）

Kotlin 原生安卓 App：接入任意兼容 OpenAI 接口格式的 AI 模型（第三方 API、Magpie 网关等），
按内置小说设定一键生成长篇小说。

## 功能（v3 新增）

- **用量仪表盘**（首页右上角柱状图图标）：每次 API 调用的 token（输入/输出）、缓存命中数与命中率、耗时与输出速度（token/秒）、花费都本地计量落盘
  - **花费币种可切换**（用量页顶部 $ / ¥ 一键切换，只显示一种，选择会记住；汇率可在全局设置改）；内置 DeepSeek（V4.1 Flash / V4 Pro，含峰谷时段自动翻倍）、GPT-4o 系列价格表，其他模型可在供应商页填自定义单价
  - **账户余额查询**：DeepSeek / 硅基流动 / Moonshot 走官方余额接口实时查；没开放余额接口的平台会明确提示（用量以本地统计为准）
  - **订阅剩余额度**：供应商填了月额度（如 OpenCode Go 的 $100）后，仪表盘按本地计量显示本月已用/剩余和进度条
  - 按模型聚合、本月总览、最近 40 次调用明细
- **故事记忆库（跨对话互通）**：每本书一份长程记忆——人物档案、关键事实、未回收伏笔、前情摘要
  - **上下文管理**：生成每章前由 ContextBuilder 按预算（全局设置，默认 6000 字）组装注入，超预算按优先级裁剪；记忆库页可预览下一章实际注入的上下文及估算 token
  - **上下文压缩**：每章写完自动抽取记忆（用大纲阶段的便宜模型）；近期摘要攒长后自动把旧摘要压缩成长程梗概
  - 记忆库可手动编辑（工作台 → 记忆库），可全局关闭
- **网上导入小说**：按书名搜索候选站点（Bing），或粘贴目录页地址解析；逐章下载整本存入书架（GBK/UTF-8 自动识别，中途停止保留已下部分）。请只下载你有权下载的内容
- **多格式导出**：TXT / Markdown / EPUB（标准 EPUB，可直接用阅读器打开），生成作品与导入的书共用

## 功能（v2）

- **多供应商配置**：一套配置 = 接口地址（base_url）+ API Key + 模型名，可存多套、一键切换，带「测试连接」
  - 内置预置：DeepSeek / OpenAI / 硅基流动 / Moonshot / Magpie / 本地 Ollama，点一下自动填地址
  - 可从接口**拉取模型列表**点选，不用手打模型名
- **分阶段模型路由**（全局设置）：大纲/细纲与正文可以指定不同的供应商——便宜模型出大纲、强模型写正文
- **内置设定库**：10 种题材 × 6 种风格 × 2 种视角，点选组合；另可填主角设定、世界观、金手指、自定义要求
- **三级生成流水线**：全书大纲 → 分章细纲 → 逐章正文；正文走**流式输出**（进度实时报已生成字数，不支持流式的接口自动回退）；每步失败**自动重试**（次数可设）；每章写完立刻存盘，**断点续写**
- **章节编辑**：标题/细纲/正文都能手动改稿；不满意的章节也能一键重写
- **导出 TXT**：整本导出并通过系统分享发出去
- **自定义系统提示词**：全局设置里可替换内置的作家角色提示词
- **首页搜索**：按书名/题材搜作品，按最近修改排序
- 数据全部存本地（JSON），不经过任何第三方服务器，请求直连你填的接口地址

## 构建

1. 用 **Android Studio** 打开本文件夹（首次打开会自动下载 Gradle 8.7 与依赖，需联网）
2. 等 Sync 完成，点 Run，或 Build → Build APK(s) 生成安装包
3. 环境要求：JDK 17（Android Studio 自带）、Android SDK 34

> 本工程在服务端环境里没有 Android SDK，未做真机编译验证；如 Sync/编译报错，把报错发回给坤坤即可逐个修。

## 使用

1. 右上角齿轮 → 添加供应商，例如：
   - DeepSeek：地址 `https://api.deepseek.com/v1`，模型 `deepseek-chat`
   - Magpie 网关：填网关给你的地址（形如 `http://<局域网IP>:<端口>/v1`）与 Key、模型名
   - 点「测试连接」确认通了，再保存
2. 首页 + 新建小说 → 选题材/风格/设定 → 创建并进入工作台
3. 点「一键生成」，等它跑完大纲、细纲和逐章正文（章节数 × 字数越大越久，中途可停）
4. 点「阅读」看全文；不满意的章节在工作台里「重写本章」

## 结构

```
app/src/main/java/com/novelforge/app/
├─ MainActivity.kt        导航入口
├─ data/Models.kt         供应商 / 小说 / 章节 数据模型
├─ data/Store.kt          本地 JSON 存储
├─ data/Templates.kt      内置设定库 + 三级提示词
├─ net/AiClient.kt        OpenAI 兼容接口客户端（OkHttp）
├─ gen/Generator.kt       生成流水线（断点续写、细纲解析）
└─ ui/                      ViewModel + 全部界面（Compose）
```
